# Obys Agency Clone

A modern and fully responsive clone of the Obys Agency website built using HTML, CSS, JavaScript, GSAP, and Locomotive Scroll. This project recreates the smooth scrolling experience, interactive cursor effects, loading animations, text reveals, and engaging UI inspired by the original Obys Agency website.

## Features
- Smooth scrolling with Locomotive Scroll
- GSAP-powered animations
- Custom cursor interactions
- Loading screen animation
- Responsive design
- Hover effects and text transitions
- Modern UI/UX

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- GSAP
- ScrollTrigger
- Locomotive Scroll
- Remix Icons
